# Оживить разделы острова после «Обзора» — дизайн

Дата: 2026-11-19. Статус: на согласовании.

## Зачем

Пользователь показал noootch (Windows, ролик @codebyreigne, 22 с) и два скрина notch-приложений
и попросил «вау» в дизайне, анимациях и функциях. На вопрос «где остров скучный» ответ:
**когда уходишь с главной страницы**. «Обзор» (музыка + календарь) устраивает, а «Фокус»,
«Полка» и «Стрик» — нет.

Разбор видео: в noootch впечатляет движение. Остров перетекает под размер каждой
страницы, а старая страница растворяется с размытием. Самих страниц там не так уж много.
У нас размеры разделов уже разные (`geometry.ts`), но содержимое подменяется без
направления и характера. Полка — три текстовые строки, Стрик — статичная сетка, у Фокуса мелкий таймер.

## Цели

1. Переход между разделами с направлением: новый раздел въезжает со стороны нажатой вкладки,
   старый уходит в противоположную сторону с лёгким blur, форма острова пружинит одновременно.
2. **Полка** — плитки вместо строк: настоящие превью файлов (картинка, кадр видео, 1-я страница PDF),
   иконка папки, карточка-текст, карточка-ссылка. Справа большая плитка-цель **«В Telegram»**.
   Файл можно вытащить с острова мышью в Проводник или в любое окно.
3. **Стрик** — при открытии сетка заполняется волной слева направо (по неделям), сегодняшняя клетка
   один раз вспыхивает янтарным, «727 вкладов» и «Серия/Рекорд» досчитываются от 0.
4. **Фокус** — крупное кольцо таймера слева, пресеты 5 / 15 / 25 / 50 мин, цифры минут
   перекидываются (flip) при смене, кольцо плавно убывает.

## Не цели

- Новые разделы (заряд устройств, текст песни, часы, погода-страница) — вариант Б отклонён.
- Точки-пагинация, цветные подсветки разделов, спутниковые пилюли — убраны 18.11, не возвращаем.
- Изменения «Обзора».

## Анти-цели (провал, даже если работает)

- Остров снова выглядит перегруженным: больше кнопок на плитке, чем 1 главное действие + меню.
- Бесконечные анимации в покое (правило 2026-10-24: idle-анимации грели DWM). Все анимации разовые,
  по событию (открытие раздела, смена цифры, добавление файла).
- Фейковые данные: превью только настоящие, сетка только из `github.rs`.
- Янтарь как украшение. Янтарь можно только для: сегодняшней клетки, кольца фокуса (живое состояние),
  подсветки цели при перетаскивании на неё.

## Ограничения

- Стек: Tauri v2, React + `motion/react`, Rust (windows-rs 0.62). Без новых JS-рантаймов.
- Визуальный язык: обсидиан, bone для основных кнопок пользователя, Onest; см. `docs/DESIGN.md`.
- Учитывать `prefers-reduced-motion`: волну, flip и blur заменять на простое появление.
- Остров не забирает фокус у окна пользователя (как у буфера).
- Ветка `clipboard-history` содержит ~43 незакоммиченных файла чужой текущей работы — новые
  изменения не смешивать с ними в одном коммите; коммитить только по просьбе пользователя.

## Подходы (рассмотрены)

- **А. Оживить три существующих раздела** — выбран пользователем. Закрывает жалобу и не
  возвращает перегруз.
- Б. А + два новых раздела (заряд Bluetooth-устройств, текст песни через LRCLIB) — эффектнее,
  но ближе к «перегружено». Отклонён.
- В. Много страниц-виджетов, как в noootch — противоречит чистке 18.11. Отброшен.

## Как устроено (решения)

### Переход между разделами
- В `PeekView` хранить направление (индекс новой вкладки больше/меньше старой).
- Контейнер раздела: `AnimatePresence mode="popLayout"` с `custom={dir}`;
  enter: `x: 24*dir, opacity 0, filter blur(6px)` → 0; exit: `x: -24*dir, opacity 0, blur(6px)`;
  пружина в духе текущей `layoutId="peek-deck-pill"` (stiffness ~420, damping ~38), ≈280 мс.
- Размер острова уже анимируется по `dimsFor` — синхронизировать по времени, не трогать формулу.

### Полка
- Ряд плиток 96×96 (как на референсе), подпись снизу с усечением по середине имени
  (`Barten…aterials`), горизонтальная прокрутка колесом при переполнении.
- Превью: переиспользовать генерацию миниатюр карточки файла (`store/files.ts`, `thumbnail`);
  если её нет для элемента — иконка типа. Папки — иконка папки.
- Наведение на плитку: лёгкий подъём (scale 1.04) и кнопки «В чат», «Показать в папке», «Убрать»
  (меню из ≤3 действий, остальное как сейчас через «Ещё»).
- Новый элемент на полке: плитка «прилетает» (scale 0.6→1, пружина), соседи раздвигаются (layout).
- Плитка-цель «В Telegram» справа: при перетаскивании файла над ней — янтарный контур и пульс
  иконки один раз; отпускание отправляет файл в «Избранное» Telegram Desktop (тем же механизмом,
  что `file_action`), по клику — отправляет выбранную плитку. После отправки — галочка на 1,3 с.
- Перетаскивание с острова наружу: нативный Windows drag (OLE `DoDragDrop` с `CF_HDROP`)
  из Rust по команде с фронта на `pointerdown`+движение > 4 px. Вариант реализации
  (свой код на windows-rs или готовый плагин `drag` для Tauri) — на выбор исполнителя после проверки,
  что плагин существует и совместим с Tauri v2.
- Строка ввода текста/ссылки остаётся, но компактнее (над плитками, как сейчас).

### Стрик
- При монтировании раздела: клетки появляются с задержкой `weekIndex * 12 мс` (opacity + scale 0.6→1),
  вся волна ≤ 650 мс. Только при открытии, не при каждом обновлении данных.
- Сегодняшняя клетка: после волны одна вспышка янтарём (box-shadow 0→8px→0, 600 мс).
- Числа: count-up 0→N за 700 мс (easeOut), `tabular-nums`.

### Фокус
- Левая колонка: кольцо 96 px (сейчас 48 в баннере; в разделе крупнее), внутри минуты крупно.
- Под кольцом — пресеты 5 / 15 / 25 / 50 (пилюли, выбранная — bone), «Старт/Пауза», «Готово».
- Смена цифры минут: flip — старая уходит вверх с blur, новая приходит снизу (motion, 220 мс).
- Кольцо убывает непрерывно через CSS transition по `stroke-dashoffset` раз в секунду (не rAF-цикл).
- Список задач справа без изменений.

## Проверка

- Тестовый стенд `qa/notch-showcase.html`: скриншоты каждого раздела и кадры середины переходов
  показать пользователю (он судит по скриншотам).
- Перетаскивание наружу и цель «В Telegram» — только в настоящем приложении; что не удалось
  проверить вживую, назвать явно.
- Замер: в покое раздел не держит анимаций (Performance → нет активных анимаций через 1 с после открытия).
