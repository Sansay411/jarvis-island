# JARVIS — визуальный язык

## Что взято из референсов

| Референс | Что забрали | Что не забрали |
|---|---|---|
| NotchNook (медиа + недельный календарь + полка Tray) | двухколоночная сетка с вертикальной 1-px разделительной линией; сквиркл обложки 54×54 со значком источника (Spotify, Яндекс Музыка, Apple Music, браузер, Telegram) и перемоткой по таймлайну; 7-дневная полоса календаря с кобальтовым активным днём `#0A84FF` и живыми задачами из SQLite; вкладка «Полка» для файлов и сниппетов | декоративные виджеты без реальных данных |
| Needt (фокус при наведении и двухколоночная дека) | компактный баннер фокуса при наведении (кольцевой обратный отсчёт, прогресс-бар, быстрые кнопки паузы и завершения); раскрытая двухколоночная дека «Фокус» с карточкой сессии слева и цветными задачами справа | перегруженные настройки внутри нотча |
| Reigne (тепловая карта активности в нотче) | 52-недельная 7-строчная изумрудная сетка активности `#13171B → #39D353` из реальных сессий, задач и локальных Git-коммитов; боковые микро-пилюли у кромки экрана (`spanW`); точки пагинации снизу и деликатное изумрудное свечение кромки | выдуманные счётчики и декоративный шум |
| «Thinking…» и голосовой режим | обсидиановая поверхность `#040406 → #08080A` с тонким бликом кромки, живые звуковые столбики, янтарная/оранжевая остановка речи в один клик | плавающие стеклянные сферы |
| Huly Dial | глубина через тон, а не через раздутый glassmorphism; тёплый акцент на нейтральном | 3D-перспектива |
| Робот с экраном-лицом | **главная идея**: остров — это лицо Джарвиса, жёлтые глаза на чёрном экране с эмоциями | голова робота как логотип (запрещено ТЗ) |

## Знак приложения

Янтарная «J» на обсидиановом сквиркле (`assets/jarvis-mark.svg`, растровый
мастер `assets/jarvis-icon.png`, сгенерирован через Codex 2026-10-24): глаз-пилюля,
который изгибается в дугу успеха. Одна толстая форма — читается в 16 px.
Прежний знак (две пилюли) отклонён: читался как морда робота и кнопка паузы.
Иконки `src-tauri/icons` пересобираются `npx tauri icon assets/jarvis-icon.png`.

## Идея

**Остров — лицо Джарвиса.** Два янтарных глаза-пилюли всегда строго в центре
верхнего ряда острова (`BROW_H = 36 px`), в защищённой центральной колонке
шириной `72 px` (`minmax(0, 1fr) 72px minmax(0, 1fr)`): вкладки слева
(`Обзор · Фокус · Полка · Стрик`) и кнопки управления справа (`Автопилот ⚡`,
буфер, голос, чат, стоп озвучки) никогда не пересекаются с глазами.

| Состояние | Глаза |
|---|---|
| покой | моргают по таймеру раз в 3,5–8,5 с, между морганиями — ноль работы |
| наведение / чат | чуть крупнее, следят за курсором по горизонтали |
| думает / выполняет | сужаются, медленно «осматриваются», лёгкое хроматическое расслоение |
| слушает / говорит (голос и TTS) | высота следует реальному уровню звука (`voice:level` и `tts:state`) |
| успех | дуги ^ ^ на 1,6 с |
| ошибка | плоские линии, коралловый цвет |
| скрыт / сон | тонкие тусклые линии |

## Токены

* Поверхность `#040406 → #08080A` → графиты `#101013 / #17171B / #202026 / #2A2A31`.
* Текст `#F2F2F0 / #A4A4AA / #6C6C74`.
* Янтарь `#FFB23F` (+ `#FFD88F`, `#E2861C`) — присутствие Джарвиса, автопилот и речь.
* Функциональные акценты состояния (только от реальных данных, без фиолетово-синих градиентов):
  * `#0A84FF` — активный день календаря и активная сессия фокуса;
  * `#22C55E` / шкала `#13171B → #0E4429 → #006D32 → #26A641 → #39D353` — стрик активности;
  * доминирующий тон обложки трека (сэмплируется на скрытом `12×12` `<canvas>`) — мягкий нижний отсвет во время воспроизведения;
  * `#7CD992` (выполнено/проверено), `#FF6B5A` (ошибка/высокий риск).
* Шрифты: **Onest** (кириллица-first гротеск) для интерфейса, **JetBrains
  Mono** для кода, таймеров и аргументов инструментов.
* Радиусы: нижние углы острова 16–24 px (растут с высотой), вогнутые верхние
  плечи 14 px, внутренние элементы 6/9/12/16.

## Геометрия (`CANVAS_W = 760`, `CANVAS_H = 640`)

| Режим | Размер (лог. px) |
|---|---|
| «губа» над развёрнутым окном (`lip`) | 132×10 |
| компактный (`compact`) | 174×36 (покой), 228×36 (медиа/фокус/TTS), 262×36 (медиа + фокус/TTS) |
| hover: баннер активного фокуса | 584×146 (+28 px на строку фоновой задачи/таймера/плана) |
| hover: дека «Обзор» (`nook`) | 616×238 |
| hover: дека «Фокус» (`focus`) | 624×294 |
| hover: дека «Полка» (`tray`) | 604×236 |
| hover: дека «Стрик» (`activity`) | 556×234 (+ боковые микро-пилюли внутри холста 760 px) |
| голос (`voice`) | 408×98 (+34 таймер, +48 подтверждение) |
| перетаскивание (`drop`) | 468×144 |
| файлы (`files`) / буфер (`clips`) | 492×156..450 / 472×174..440 |
| рабочее пространство (`workspace`) | 528×492 |

Форма — аппаратный нотч: плоский верх вровень с `y = 0`, вогнутые плечи радиусом
14 px (`SHOULDER = 14`), тонкий 1-px блик нижней кромки. Пружина формы:
stiffness 380, damping 28, mass 0.8; при `prefers-reduced-motion` — почти мгновенно.

## Движение

Движение отвечает на действие пользователя или на смену состояния агента.
Контент меняется через короткое растворение с размытием 6 px после того,
как форма начала расти. В покое ничего не анимируется непрерывно.
