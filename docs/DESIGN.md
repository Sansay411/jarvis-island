# JARVIS — визуальный язык

## Что взято из референсов

| Референс | Что забрали | Что не забрали |
|---|---|---|
| Notch-приложения macOS (медиа + календарь, зона «Drop files here») | остров, свисающий с края экрана; медиакарточка с обложкой; пунктирная зона сброса | вкладки-иконки в верхнем ряду, календарь (нет данных — не рисуем фейк) |
| «Thinking…» со стеклянными сферами | тёмная поверхность с едва заметным светом сверху, поле ввода-пилюля с тонкой рамкой | плавающие сферы как декор |
| Голосовой режим ChatGPT | светящиеся вертикальные «пилюли», живущие от звука; оранжевая кнопка стоп | — |
| Huly Dial | глубина через тон, а не через тени; тёплый акцент на нейтральном | 3D-перспектива |
| Робот с экраном-лицом | **главная идея**: остров — это лицо Джарвиса, жёлтые глаза на чёрном экране с эмоциями | голова робота как логотип (запрещено ТЗ) |
| Стеклянная иконка | матовые слои на чёрном сквиркле для иконки приложения | — |

## Идея

**Остров — лицо Джарвиса.** Два янтарных глаза-пилюли всегда в центре
верхнего ряда острова, в любом состоянии. Это единственный «громкий» элемент;
всё вокруг — тихое и монохромное.

| Состояние | Глаза |
|---|---|
| покой | моргают по таймеру раз в 3,5–8,5 с, между морганиями — ноль работы |
| наведение / чат | чуть крупнее, следят за курсором по горизонтали |
| думает / выполняет | сужаются, медленно «осматриваются», лёгкое хроматическое расслоение |
| слушает / говорит | высота следует реальному уровню звука |
| успех | дуги ^ ^ на 1,6 с |
| ошибка | плоские линии, коралловый цвет |
| скрыт / сон | тонкие тусклые линии |

## Токены

* Поверхность `#08080A` → графиты `#101013 / #17171B / #202026 / #2A2A31`.
* Текст `#F2F2F0 / #A4A4AA / #6C6C74`.
* Янтарь `#FFB23F` (+ `#FFD88F`, `#E2861C`) — только присутствие Джарвиса и
  живые состояния. Никаких фиолетово-розовых градиентов.
* Исходы: `#7CD992` (проверено), `#FF6B5A` (ошибка/высокий риск).
* Шрифты: **Onest** (кириллица-first гротеск) для интерфейса, **JetBrains
  Mono** только для реального кода и аргументов инструментов.
* Радиусы: остров 15–26 px (растёт с высотой), внутренние элементы 6/9/12/16.

## Геометрия

| Режим | Размер (лог. px) |
|---|---|
| компактный | 168×34, 212×34 с медиа |
| hover | 412×104, 452×136 с медиа |
| перетаскивание | 440×132 |
| голос | 380×132 |
| рабочее пространство | 528×492 |

Форма — нотч: плоский верх, вогнутые «плечи» радиусом 10 px, скругление низа
растёт с высотой. Пружина формы: stiffness 380, damping 28, mass 0.8; при
`prefers-reduced-motion` — почти мгновенно.

## Движение

Движение отвечает на действие пользователя или на смену состояния агента.
Контент меняется через короткое растворение с размытием 6 px после того,
как форма начала расти. В покое ничего не анимируется непрерывно.
