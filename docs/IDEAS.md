# Возможности Jarvis: рабочие идеи

Статус: 23 октября 2026 реализованы «Файл на острове» (без PDF-объединения и 3D), отправка в «Избранное» через Telegram Desktop, таймеры и напоминания. Остальное — задумки.

Главный приоритет сейчас: стабильный отклик на имя, быстрый голос, плавное открытие, отсутствие потерянных команд и понятный результат каждого действия. Новые интеграции добавлять после этого.

## Заметки и напоминания

Первый функциональный модуль после стабилизации. Разделить заметку, задачу и напоминание. Голосовое создание и редактирование, поиск по тексту, проекты и теги, повторяющиеся напоминания, «Готово», «Позже», «Перенести». Файл или ссылка могут быть прикреплены к заметке.

Хранить в SQLite, запускать по локальному расписанию, независимо от модели и интернета. После сна или перезапуска показывать пропущенное; одинаковое событие не должно приходить повторно. При закрытом приложении нужен отдельный механизм Windows. На выключенном компьютере локальный Jarvis уведомить не сможет.

Примеры: «Запиши мысль», «Напомни завтра в десять», «Напомни про этот файл вечером», «Когда сборка закончится, скажи мне». Подтверждение создания должно показывать конкретную дату и время. Неоднозначное «после обеда» уточнять.

## Файл на острове

Пользователь перетаскивает файл, Jarvis определяет тип по содержимому и предлагает 3–5 подходящих действий. Отдельная кнопка открывает остальные возможности. Никакой автоматической отправки или конвертации при сбросе.

Общие действия: прикрепить в чат, отправить оригинал в «Избранное» Telegram, открыть, показать в папке, скопировать путь, создать заметку или напоминание с этим файлом.

| Тип | Дополнительные действия |
|---|---|
| Изображение | Предпросмотр, извлечь текст, конвертировать в совместимый формат, убрать метаданные по просьбе |
| PDF | Читать и искать, выделить страницы, объединить, извлечь текст, распознать скан |
| Документ или таблица | Предпросмотр, краткое содержание, экспорт PDF, извлечение таблиц |
| Аудио | Расшифровка, субтитры, извлечь дорожку, конвертация |
| Видео | Извлечь звук или кадр, субтитры, сменить контейнер, конвертация |
| Архив | Посмотреть содержимое, распаковать в выбранную папку, собрать архив |
| 3D-модель | Предпросмотр, размеры с явным указанием единиц, сведения о геометрии |
| Несколько файлов | Прикрепить вместе, отправить оригиналы, архивировать, пакетное преобразование совместимых типов |

Интерфейс: иконка типа, имя, размер, превью при наличии, затем действия. Длительная операция выполняется в фоне с прогрессом и отменой. Результат можно открыть, показать в папке, прикрепить в чат или отправить. Оригинал сохраняется; результат записывается отдельным файлом. Неподдерживаемый или повреждённый файл должен давать понятную ошибку.

### Что означает «без потери качества»

Показывать такую подпись только там, где её можно подтвердить. Копирование оригинала сохраняет байты. Перекладка совместимого аудио/видео в другой контейнер может обойтись без перекодирования. Для изображений возможны форматы с обратимым сжатием, но нужно учитывать прозрачность, цветовой профиль и разрядность.

JPEG → PNG сохраняет уже декодированное изображение, не возвращает утраченное качество и может увеличить размер. MP3 → FLAC тоже не восстанавливает потерянное. PDF → Word, уменьшение разрешения и повторное кодирование видео не должны обещать отсутствие потерь. Для них нужны честное название операции, настройки и предварительный просмотр.

### Telegram: именно своё «Избранное»

Предпочтительный вариант: подключённая пользовательская сессия Telegram с фиксированным получателем «я». Отправка через API привязывается к собственной учётной записи, а не к окну, которое случайно оказалось на переднем плане. Документация: [inputPeerSelf](https://core.telegram.org/constructor/inputPeerSelf), [работа с файлами](https://core.telegram.org/api/files).

Подключение аккаунта потребует отдельного согласия пользователя. Перед отправкой показывать файл и получателя «Избранное». Фото и видео по умолчанию отправлять оригинальным файлом; подтверждать завершение только после ответа Telegram. Обычный чат с ботом не считать пользовательским «Избранным».

## Следующие полезные функции

1. Локальные заметки, задачи и надёжные напоминания.
2. Готовые сценарии «Начинаем работать», «Верни рабочее окружение», «Заканчиваем день» с настраиваемыми действиями.
3. Поиск по выбранным пользователем рабочим папкам: найти файл по смыслу, открыть последнюю версию, показать источник ответа.
4. Уведомления о завершении загрузки, сборки и фоновой задачи с проверкой реального результата.
5. Контекстные просьбы: «Сохрани эту ссылку», «Объясни выделенное», «Напомни об этом», с видимой привязкой к выбранному источнику.
6. История обратимых действий и «Отмени последнее», когда инструмент действительно поддерживает восстановление.

Критерий готовности новой функции: она работает в настоящем сценарии, корректно обрабатывает ошибку и отмену, сохраняет данные и показывает честный статус. Демонстрация интерфейса сама по себе этого не подтверждает.
