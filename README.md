Джарвис живёт в маленьком острове у верхнего края экрана. Наведите курсор — раскроется командный хаб с музыкой, календарём задач, таймером фокуса, полкой файлов и картой активности; кликните или нажмите `Ctrl+Alt+J` — откроется чат. Скажите «Джарвис» или нажмите `Ctrl+Alt+K`, и он слушает. Два янтарных глаза в центре всегда показывают, что он делает: думает, слушает, говорит, рад или растерян.

Это не болталка. Джарвис меняет громкость и яркость, запускает программы, раскладывает окна по сетке, ведёт пошаговый план задачи, читает вкладки браузера и выделенный текст, конвертирует файлы, следит за сессиями фокуса и озвучивает сводки чистым нейросетевым голосом. После каждого действия он проверяет результат и только потом отвечает.

## Установка

1. Откройте [последний релиз](https://github.com/Sansay411/jarvis-island/releases/latest).
2. **Windows:** скачайте **`Jarvis-x.y.z-Setup.exe`** и запустите — установщик сам всё поставит, права администратора не нужны.
   **macOS:** скачайте DMG для своего Mac (`aarch64` — Apple Silicon, `x64` — Intel) и перетащите Джарвиса в «Программы».
3. Джарвис появится вверху экрана и в трее.

Дальше Джарвис обновляется сам: раз в шесть часов проверяет релизы на GitHub и предлагает поставить новую версию в один клик (пакет проверяется подписью). Проверить вручную — «Настройки → Основное → Обновления» или пункт в трее.

Если не хочется устанавливать, в релизе есть **`jarvis-portable.exe`**. Это один файл, его можно запускать откуда угодно. Ему нужен WebView2, в Windows 11 он уже есть. Portable-версия не обновляется сама.

> [!NOTE]
> Windows SmartScreen может предупредить о неизвестном издателе: сборка пока не подписана сертификатом (подпись подключается, см. [Code signing policy](#code-signing-policy)). Нажмите «Подробнее», затем «Выполнить в любом случае».

**Удаление:** «Параметры → Приложения → Jarvis → Удалить». Откроется окно в том же стиле, что и установщик. Голосовые модели и кэш удаляются по умолчанию, а настройки, история и ключи API — только если отметить их галочкой: иначе после переустановки всё вернётся как было.

## Первый запуск

1. Откройте настройки через меню в трее.
2. В разделе **«Модель»** выберите провайдера, вставьте API-ключ и нажмите «Проверить подключение». Для Ollama ключ не нужен.
3. В разделе **«Голос»** студийные голоса **Edge Neural HD** (*Дмитрий HD*, *Светлана HD*, *Andrew Multilingual HD*, *Ryan HD*) уже включены бесплатно и без ключей — нажмите «Прослушать» или «Замерить задержку». Для голосового ввода с микрофона скачайте локальное распознавание GigaAM v3 (170 МБ), а для работы полностью без интернета — локальный голос Supertonic 3 (129 МБ) или Piper.

При отсутствии сети Джарвис автоматически переключается на скачанный локальный нейросетевой голос или системный голос Windows.

> [!IMPORTANT]
> Голосовое распознавание пока понимает только русский язык. Чат и все действия работают на любом языке, который понимает выбранная модель.

## Безопасность

Джарвис управляет настоящим компьютером, поэтому осторожность встроена в каждое действие.

* **Чтение выполняется сразу.** Изменения файлов, команды и закрытие окон идут с подтверждением, это настраивается.
* **Опасное подтверждается всегда.** Удаление, установка, отправка сообщений, нажатия на «Отправить», «Удалить», «Купить». Enter в мессенджере тоже считается отправкой, и в подтверждении видно, кому уходит сообщение.
* **Чужой текст не командует.** Страницы, файлы, буфер обмена и вывод команд передаются модели как недоверенные данные.
* **Снимки экрана и звук не сохраняются на диск.** Экран снимается только по ходу задачи.
* **Ключ модели уходит только на тот адрес,** для которого он сохранён.
* **Инструменты MCP проходят те же проверки.** Разрушительные подтверждаются каждый раз, даже в режиме полного управления.
* **Все рискованные действия записываются** в журнал `audit_log` в `%LOCALAPPDATA%\dev.jarvis.desktop\jarvis.db`.

## Конфиденциальность

У Джарвиса нет своего сервера, аккаунтов и телеметрии. Речь распознаётся на компьютере, а в сеть уходит только то, что вы включили: запросы к выбранному вами провайдеру модели, облачные голоса, погода по просьбе и проверка обновлений на GitHub. Подробно, что и куда, — в [PRIVACY.md](PRIVACY.md).

## Сборка из исходников

<details>
<summary><b>Что понадобится и как собрать</b></summary>

<br>

* Windows 10 или 11, x64
* [Rust](https://rustup.rs) stable с MSVC
* Visual Studio Build Tools с компонентом «Desktop development with C++» и Windows SDK
* Node.js 20 или новее
* WebView2 Runtime

```bash
npm install
npm run tauri dev
```

Установщик собирается так:

```bash
npm run tauri build
```

Готовый файл появится в `src-tauri/target/release/bundle/nsis`. Собирайте релиз только через `tauri build`: обычный `cargo build --release` грузит интерфейс с dev-сервера.

При первой сборке `sherpa-onnx-sys` скачивает готовые библиотеки sherpa-onnx. Они собраны со статическим CRT, поэтому всё приложение линкуется с `+crt-static`, и Visual C++ Redistributable пользователю не нужен.

</details>

<details>
<summary><b>Диагностика</b></summary>

<br>

* Журнал: `%LOCALAPPDATA%\dev.jarvis.desktop\logs\jarvis.log`
* В настройках есть раздел «Диагностика»: память, мониторы, задержки голоса.
* Нативные интеграции проверяются без интерфейса:

```bash
cargo run --example probe -- audio
cargo run --example probe -- windows
cargo run --example probe -- browser
cargo run --example probe -- asr a.wav
cargo run --example probe -- files-run convert:png photo.heic
cargo run --example tts_bench
```

</details>
